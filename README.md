# Central 3D Ostras

App de gestão da 3D Ostras: painel, calculadora de custo, propostas em PDF, vendas, produtos, investimento, testes, relatórios e parâmetros.

- Site: https://henriquearte7-lab.github.io/central-3d-ostras/
- Dados: Planilha Google "Central 3D Ostras — dados", acessada pelo script `apps-script-Codigo.gs` (Apps Script publicado como App da Web).
- Acesso protegido pelo PIN definido no script.
